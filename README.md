# BLACC Universal

Website for BLACC Universal — Beyond Limits And Conventional Constraints.

Plain HTML, CSS and JavaScript, deployed on Netlify. No build step.

- `index.html` — Home
- `about/` — About
- `projects/` — Projects (coming soon)
- `shop/` — Shop (coming soon)
- `404.html` — Page not found
- `assets/` — styles, script, images

"Notify me" sign-ups on Projects and Shop are collected by Netlify Forms (form name: `notify`).
