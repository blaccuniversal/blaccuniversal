    How to play
    1. Pick a category. Take turns adding one word from it. Each word goes on its own row, one letter per box.
    2. Every word scores. 1 point for the first letter, 2 for the second, and so on. 3 letters = 6, 5 letters = 15, 8 letters = 36.
    3. Maverick. Read straight down any column from the 2nd letter onwards. If 3 or more rows in a row spell a word from the same category, the player who finished it scores it like a word.
    4. Concord. 5 or more words in a row with the same length (3+ letters). Each word in the streak scores (length − 1) + (streak − 5), so it grows while the streak lasts.
    5. Keystone. If one word sets off a Maverick and a Concord at the same time, it earns 5 extra points.
    6. Checking. Words are checked against the category's word list. If a real word isn't in the list, the table can agree to count it anyway. A word can only be used once per round.
    7. Rounds. A round ends when the timer runs out, the word limit is reached or you end it. Scores carry over between rounds.
