          How to play
          1. Pick a category. Take turns adding one word from it. Each word goes on its own row, one letter per box.
          2. Every word scores. 1 point for the first letter, 2 for the second, and so on. 3 letters = 6, 5 letters = 15, 8 letters = 36.
          3. Maverick. Read straight down any column from the 2nd letter onwards. If 3 or more rows in a row spell a word from the same category, the player who finished it scores it like a word.
          4. Letter rule (optional). Sorted: each word sorts after the one above, skipping allowed. Ladder: the next word starts with the next letter (A, B, C… back to A after Z), one word per letter. Lap: everyone plays the same letter, then the table moves on. In Ladder and Lap, no word? Tap No word: the letter is passed for 0 points. Another player can tap I have one and, with a real word, scores it plus 3.
          5. Concord. 3 or more words in a row with the same length (3+ letters). Each word in the streak scores (length − 1) + (streak − 3), so it grows while the streak lasts.
          6. Regen. Spell a word with exactly the same letters as the word above yours (an anagram, 3+ letters, like STAR after RATS). It scores its length plus 1 in bonus points (3 letters = 4, 4 = 5, 5 = 6, and so on), on top of the normal word score.
          7. Keystone. If one word sets off a Maverick and a Concord at the same time, it earns 5 extra points.
          8. Checking. Words are checked against the category's word list. If a real word isn't in the list, the table can agree to count it anyway. A word can only be used once per round.
          9. Rounds. A round ends when the timer runs out, the word limit is reached or you end it. Every round starts at zero, and the game total adds up all the rounds.
