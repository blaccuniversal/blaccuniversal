Written Round

The question, then the answer on the next line. Empty line between questions. For options, write them in the question as [A] … [B] …; for true or false, end the question with True or false? They show on their own lines.

Rapid Fire

The question, then the answer. Add image: /path.png on a third line to show a picture. Empty line between questions.
